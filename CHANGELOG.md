# Changelog

All _notable_ changes to this project will be documented in this file.

The format is based on [Keep a Changelog][keep-a-changelog] (v1.1.0) and this
project adheres to [Semantic Versioning][semver] (v2.0.0.).

> **Note**: This changelog is written for **end-users**. It focuses on new
features, bug fixes, and documentation improvements. Aspects such as internal
maintenance, tooling updates, and library refactors are generally excluded
unless they impact the user experience.

## Unreleased

## [0.2.0] - 2026-03-19

### Added

- A **style** scope to `chore` for purely stylistic or system-level linting
tasks that do not change code behavior.
- Sample issues to `fix` scopes.
- Guidance for resolving **code smells** and **complexity warnings** within the
**cleanup** and **debt** scopes of `refactor`.

### Changed

- Generalized `epic` issue template scope descriptions to be domain-agnostic.
- Updated `fix(deps)` scope to focus on functional regressions and broken
dependency functionality.
- Updated `docs` scope validation to **required**.

## [0.1.0] - 2026-03-17

### Added

- Organization-wide issue forms: chore, docs, epic, feat, fix, refactor, task,
and test.
